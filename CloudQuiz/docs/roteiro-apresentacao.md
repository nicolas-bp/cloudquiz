# Roteiro rápido para apresentação

“Nosso projeto é o CloudQuiz, um mini-game de perguntas e respostas com foco em conceitos de tecnologia. O jogador responde cinco questões, recebe feedback imediato e ganha cem pontos por acerto.

No frontend usamos HTML, CSS e JavaScript. Para o backend escolhemos o Back4App, que utiliza Parse Server e pode fornecer autenticação e persistência das pontuações. O GitHub mantém o histórico do código e executa verificações automáticas pelo GitHub Actions. O Azure Static Web Apps é a opção de publicação do frontend.

O projeto separa a interface da camada de dados. Também consideramos requisitos funcionais, como jogar, calcular pontuação e exibir o placar, e não funcionais, como responsividade e feedback rápido.

Na demonstração, vamos iniciar uma rodada, responder às perguntas, conferir a pontuação e atualizar o placar. As funções de nuvem serão demonstradas após configurar e validar as credenciais e o deploy.”

**Antes de apresentar:** substitua esta fala por uma descrição fiel do que realmente foi configurado e testado. Não diga que o Back4App ou Azure funcionou se ainda não foi validado.
